01 · About

Most automation stops one step short. It drafts the thing, then waits for you to file it, send it, and remember the follow-up. I build agents that carry a task all the way to done — research it, write it, deliver it to the right place, and set the reminder — without checking in at every step.

In practice that means custom Claude automations wired into the tools teams already use — Google Workspace, Slack, and more. I bring in extra data stores and services when a job needs memory or retrieval. Both projects below run end to end — one of them on a schedule, with no prompt at all.
